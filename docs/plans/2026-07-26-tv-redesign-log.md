# 電影與影集整合、紅黑電影感改版紀錄

## 範圍

- 首頁新增電影／影集切換，兩者都有最新、趨勢、熱門與高評分區塊。
- 類型篩選改為單一 6 欄無限列表；一般區塊每次顯示 12 筆。
- 搜尋、收藏、詳細頁與 AI 推薦支援電影及影集。
- 移除隨機挑片、Top 100、跑馬燈與海報 hover 預告片。

## 資料與互動決策

- 電影最新使用 TMDB `now_playing`，影集最新使用 `on_the_air`。
- 影集詳細頁顯示季數、總集數、下一集播出日、aggregate credits 與影片。
- 收藏識別由單一 ID 改為 `(media_type, id)`，避免電影與影集同 ID 衝突。
- AI 使用原生 Checkbox；預設電影、至少一項。雙選時回傳 3 部電影與 3 部影集，單選時回傳 6 筆。
- 海報卡片 hover 只旋轉 360 度一次，並尊重 reduced-motion。

## 視覺方向

- 主背景 `#0B0B0E`、卡片 `#17171B`、重點紅 `#D62B42`。
- 保留首圖文字漸層與打字效果，改為白紅漸層。
- 首圖背景使用 TMDB 真實 backdrop，採非對稱左對齊內容。
- 移除原本綠色與藍色介面重點色、跑馬燈與捲動提示。

## 驗證

- `bun run test:run`
- `bun run lint`
- `bun run build`
